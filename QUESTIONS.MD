1. Зачем добавлять папку PHP в переменную PATH и как проверить, что PHP установлен?
Чтобы команда php работала из любого окна CMD без указания полного пути
2. Какой командой запускается встроенный сервер PHP и как указать другой порт или корневую папку?
php -S localhost:8000. Другой порт: php -S localhost:8080. Корневая папка: ключ -t, (php -S localhost:8000 -t C:\projects\filemanager)
3. Почему форма загрузки не работает без enctype="multipart/form-data"?
Без этого атрибута браузер отправляет только имя файла как строку, а не сам файл. Массив $_FILES остаётся пустым.
4. Какие ключи содержит массив $_FILES['userfile'] и что хранится в tmp_name?
name (исходное имя), full_path, type (MIME), tmp_name (путь к временному файлу), error (код ошибки), size (размер в байтах). В tmp_name - путь к временному файлу, который PHP создаёт при загрузке; он удаляется после завершения скрипта.
5. Чем move_uploaded_file() отличается от copy()?
move_uploaded_file() дополнительно проверяет, что файл действительно загружен через HTTP POST (защита от подмены пути). copy() такой проверки не делает.
6. Чем отличаются директивы upload_max_filesize и post_max_size? Какое значение должно быть больше и почему?
upload_max_filesize - предел размера одного файла. 
post_max_size - предел всего POST-запроса (все файлы + поля формы). post_max_size должно быть больше, потому что запрос может содержать несколько файлов и другие данные формы.
7. Что произойдёт с массивами $_POST и $_FILES, если запрос больше post_max_size?
Оба массива будут полностью пустыми. В журнале PHP появится предупреждение.
8. Почему upload_max_filesize нельзя изменить через ini_set()?
Потому что файл уже принят сервером до запуска скрипта. Настройка применяется на этапе приёма данных, а ini_set() работает уже внутри скрипта.
9. Для чего при удалении и сохранении файлов используется basename()?
Чтобы отсечь возможные ../ в имени файла и не дать злоумышленнику выйти за пределы папки uploads (защита от path traversal).
10. Почему нельзя разрешать загрузку файлов с расширением .php?
Потому что такой файл можно будет открыть через браузер, и сервер выполнит его как PHP-скрипт. Это даёт атакующему возможность выполнить произвольный код на сервере.
